# 心动像素 Pixel Heart ❤

一款**情侣双人同屏合作**的微信小游戏,复古像素风格,纯 Canvas 编写、无任何外部图片/音频资源,代码即玩。

**4 关连续挑战,每关难度递增、掉落物种类不同**,通关看默契,全通拿评级!

```
你 ← 守左边    |    TA → 守右边
────────────────────────────────
  第 1 关  心动初识   只有红心,热身上手
  第 2 关  甜度加倍   + 金心(+3)、坏心情炸弹
  第 3 关  默契挑战   + 彩虹心(+5 并清除全场炸弹)
  第 4 关  灵魂之约   全掉落物,速度/密度终极考验
────────────────────────────────
每 10 连击奖励爱心;每过一关奖励爱心(上限 5)
爱心归零 → 止步结算;4 关全通 → 通关评级
```

- 双人同屏:两人各守一侧,双手**可同时操作**(多点触控)
- 实在没人陪?一个人也能玩,练手即可
- 真机带震动反馈(接中轻震 / 连击中震 / 心碎强震)

## 一、文件结构

```
pixel-love/                  ← 微信小游戏工程(直接导入微信开发者工具)
├── game.js                  ← 全部游戏逻辑 + 像素绘制 + 多点输入(唯一核心)
├── game.json                ← 竖屏配置
└── project.config.json      ← 开发者工具工程配置

pixel-love-preview/          ← 浏览器试玩(仅本地体验用,与发布无关)
├── preview.html             ← 双击即可在浏览器试玩
└── wx-shim.js               ← 把 wx API 映射到浏览器 DOM
```

> 核心只有 `game.js` 一个文件:它在微信小游戏运行时里直接用 `wx.*`,
> 在浏览器里则复用预览页提供的同一套 `wx` 全局对象,**同一份代码无需改动**。

## 二、快速体验(浏览器)

直接双击打开 `pixel-love-preview/preview.html`(或拖进任意浏览器)。
桌面端用鼠标即可模拟点击;真触屏设备上支持双指同时操作,可模拟双人场景。

## 三、在微信开发者工具中运行(真机预览)

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html);
2. 打开工具 →「小程序」→「导入项目」;
3. 目录选择本仓库的 **`pixel-love`** 文件夹;
4. AppID:无账号可选 **「测试号」(游客模式)**;有账号则填你的小游戏 AppID;
5. 导入后点击「编译」即可在模拟器游玩,点「预览」扫码即可在手机上真机试玩(双人同屏多点触控 + 震动)。

> 提示:小游戏类目与小程序类目不同,若要**发布上线**,需在
> [微信公众平台](https://mp.weixin.qq.com) 注册 **「小游戏」** 类型账号获取正式 AppID,
> 并在 project.config.json 中替换 `"appid"`。

## 四、关卡与规则明细

| 掉落物 | 操作 | 结果 |
| --- | --- | --- |
| 红色爱心 | 点击接住 | +1 分,连击 +1 |
| 金色爱心(第 2 关起) | 点击接住 | +3 分,连击 +1 |
| 彩虹心(第 3 关起) | 点击接住 | +5 分,连击 +1,**清除全场炸弹** |
| 黑紫炸弹(带火花) | **不要点**,让它落地 | 落地无害消失,但连击清零 |
| 黑紫炸弹 | 误点 | 爆炸!爱心 -1,连击清零,屏幕红闪 |

- 红心/金心/彩虹心落地未接住 → 爱心 -1(心碎)
- 爱心归零 → 提前止步结算;每关时间用完 → 过关(第 1~3 关)或通关(第 4 关)
- 结算给出:总得分、最高连击、命中率、默契评级(S/A/B/C/D)+ 一句情话
- 历史最高分本地自动保存,下次打开仍在

### 各关参数一览(`LEVELS` 数组)

| 关卡 | 名称 | 时长 | 生成间隔(秒) | 下落速度 | 炸弹权重 | 金心权重 | 彩虹权重 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 心动初识 | 28s | 0.74 → 0.56 | 115 → 175 | 0 | 0 | 0 |
| 2 | 甜度加倍 | 30s | 0.64 → 0.46 | 140 → 225 | 0.10 | 0.10 | 0 |
| 3 | 默契挑战 | 34s | 0.56 → 0.40 | 170 → 275 | 0.18 | 0.11 | 0.045 |
| 4 | 灵魂之约 | 40s | 0.52 → 0.34 | 200 → 340 | 0.24 | 0.12 | 0.055 |

> 生成间隔 / 下落速度在本关内随时间从「开始值」爬升到「终值」;
> 权重为各掉落物占生成量的比例,红心占剩余部分。

## 五、进阶定制(都在 game.js 顶部)

| 想改什么 | 改哪里 |
| --- | --- |
| 关卡数/每关时长/难度/掉落物权重 | `LEVELS` 数组(每关:name、time、spawnInt、speed、bombW、goldW、rainbowW、hint、theme) |
| 每关配色主题 | 对应关卡的 `theme`(top/bottom/ground) |
| 评级分数线与情话 | `RANKS` 数组 |
| 通用配色 | `COL` / `RAINBOW` 调色板 |
| 像素造型 | `MAP_HEART` / `MAP_BOMB` / `FONT` 贴图 |

## 六、技术要点

- 主循环 `requestAnimationFrame`,`dt` 限幅防切后台跳帧;
- 状态机:菜单 / 游戏中 / 过关面板 / 结算(通关与止步两套文案);
- 触控用 `wx.onTouchStart` 的 `changedTouches` 遍历,天然支持多点;
- `wx.onShow / onHide` 自动暂停/恢复;
- 每关切换时重建离屏渐变背景,避免每帧创建 gradient;
- 全部像素图形用「01 字符画 + 逐格 fillRect」程序化绘制,零资源依赖(彩虹心逐格循环取色);
- 震动用 `wx.vibrateShort`(web 预览降级为 `navigator.vibrate`)。
